# Capstone-Retail-Performance-Analysis
Retail Sales Analytics Dashboard analyzing 3M orders and $8.58M revenue. Built with Excel, SQL, Python (RFM + KMeans) &amp; Power BI to track sales, products and customer segments (Loyal, At-Risk, Champions) for business growth.
# About
This project analyzes retail bike sales data of 3M orders and $8.58M revenue using Excel, SQL, Python and Power BI to track sales, product performance and customer segmentation with RFM and KMeans for data-driven business decisions.
# Tools
Excel,Sql,Python,Powerbi
